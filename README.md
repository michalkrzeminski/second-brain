# Knowledge Base – Architecture & Data Engineering

This repository serves as my personal knowledge base for **Software Architecture** and **Data Engineering**.

Its purpose is to collect, organize, and continuously refine knowledge gathered from:

- hands-on experience
- technical documentation
- books and courses
- conferences
- industry best practices

## Topics covered

- Software Architecture and Design Patterns
- Data Engineering concepts and best practices
- Azure and Databricks
- Data Lakehouse architectures
- Event-driven architecture
- Distributed systems
- System design
- Cloud-native solutions
- CI/CD and DevOps
- AI and LLM applications in software engineering
- Performance optimization
- Architecture Decision Records (ADRs)
- Notes from certifications, books, and technical articles

## Goal

Build a structured, searchable, and practical reference that supports continuous learning and can be used as a quick knowledge source when designing, building, and operating modern data platforms.
